# 审查证据

仅在确定比较快照、读取远程审查材料或复审时读取。具体工具、认证和平台操作由当前环境的能力与适用指令决定，本 skill 不指定客户端或接口。

## 固定审查快照

确认目标项目、审查请求、比较基准和待审版本，记录可核验的版本标识（例如提交 SHA）。远程请求已声明比较范围时采用其实际快照，不用本地分支猜测替代。

核验变更材料完整性，注意分页、截断、折叠或未展示文件；部分结果不能称为完整变更。源码、删除内容和重命名前后路径须与比较快照对应。本地版本不同或工作区有其他改动时，读取对应版本的材料，不覆盖现有工作。

检查相关讨论、已有审查意见、当前版本的验证状态及必要日志。旧版本成功不能代表当前通过；按风险核对消费者、依赖解析结果和相关历史。连续复审时说明上次版本、本次增量与仍适用的契约。

## 范围覆盖记录

从已确认的完整变更范围建立文件清单，保留路径与变更状态，区分删除、重命名或同一路径的不同变更。每项记录为“已审查”或“未审查＋具体原因”；只读取文件不等于完成审查。明确排除的项另记范围依据，不能把检查失败改称范围排除，也不默认忽略锁文件、配置或二进制的契约影响。

按关联风险组织检查，例如将实现、配置、资源和消费者一起核对；语言或职责规则按需加载。分批或复用已有检查不应遗漏清单项，不因已发现一个严重问题提前宣称审查完成。

交付前汇总范围内文件数、已审查数与未审查数，并列出未审查项的原因及其对结论的影响；详细清单可留本轮产物。全部文件已审查仅说明范围覆盖，不保证不存在漏检，也不代表完成运行验收。

## 复用与刷新

已核实的固定快照材料可复用。比较基准、待审版本、相关依赖解析结果或工具链变化时刷新受影响证据；即使版本相同，新讨论、CI 或用户补充仍可能改变结论。

取证结束时核对比较快照是否变化，不能混用版本。持续变化或访问缺口时报告已覆盖部分与未完成项，不以本地辅助分析替代完整远程审查。外部写入前另按 [评论发布规则](comments.md) 核对当前目标与快照。
