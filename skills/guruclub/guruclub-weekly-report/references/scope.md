# 周报范围确认


第一项业务动作是弹出范围确认框，不要先扫描项目会话、读取仓库/MR 或生成内容。允许先解析本次请求已有参数、读取当前日期，以及阅读本技能所需指令。

使用当前环境允许用于必要范围确认的交互输入工具，展示一个“汇总范围”问题。工具若仅支持可选问题，不把它当作必答门槛；可用时选择能保持问题待答的工具，否则用简短文字询问。不要绑定某个客户端独有的工具名。

问题写明来源、统计起止、补充要求与默认排除项；有选项时提供“按以上范围”和“修改或补充范围”，同时允许自由输入。

无参数时显示这些默认值：

| 参数 | 默认值 |
| --- | --- |
| 来源 | GuruClub：git.gelonghui.com 的 ios/guruclub 仓库及相关项目会话 |
| 统计区间 | Asia/Shanghai，本周一 00:00 至本次手动触发时刻，弹框内换算为具体日期 |
| 工作归属 | 用户本人的工作，不把他人工作算入 |
| 内容范围 | iOS 的实质性成果，默认不含 Android；用户可明确修改 |
| 输出 | 一句话标题和表格预览；不自动写入 Confluence |

即使调用中已给出来源和日期，也先展示这些参数供确认。用户可以追加来源，也可以完全替换为非 GuruClub 项目、指定会话/文档或手工补充的工作；不要强制保留 GuruClub、GitLab 或 iOS 限制。

回答处理：

- 确认选项表示同意展示的参数。
- 有明确自由文本时直接按其含义追加或替换，并用一句话回述本次范围后开始，不再重复弹框。
- 仅选“修改或补充”而未填写内容时，再用输入工具询问要改什么。
- 未得到确认或有效修改时，保持待确认，不收集业务资料。空答案、取消、超时和预选项均不是同意；必要问题保持待答，不反复弹出同一问题。不能弹框时如实说明并接受文字回答。
