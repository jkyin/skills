# 周报汇总（默认 GuruClub）

将本周本人完成或推进的实质性工作整理成一句话标题和中文表格。来源默认 GuruClub，可追加或完全替换。

## 调用与范围

- 保留 `agents/openai.yaml` 的 `policy.allow_implicit_invocation: false`。只响应明确点名、技能选择器或计划任务显式调用；讨论或修改本 skill 不执行周报。
- 同一次调用的范围回答、修订和写入确认延续生效；新周报重新确认范围，不继承旧项目清单、例外或页面授权。
- 明确“仅提醒”时读取 [提醒模式](references/reminder.md)，提醒后结束。其余调用进入汇总模式。
- 汇总的第一项业务动作是按 [范围确认](references/scope.md) 展示来源、具体起止时间和要求，即使已给完整参数也保留本轮首次确认。范围尚未确认时不采集业务资料，空回答不算确认。

## 汇总与交付

1. 确认后按 [证据与归属](references/evidence.md) 收集，GitLab 使用 `glab`，只查本次来源。记录本人归属、本周活动、实际成果、阶段和验证依据。
2. 按 [表格与写作](references/report-table.md) 输出完整预览。聚焦产品成果，纯依赖升级合并；不将工程过程或缺证据的完成结论写进正文。
3. 只要求生成周报时，完整预览及必要待核实点即为交付。用户修订时继续同一流程，不重复要求点名 skill。
4. 用户批准完整预览且要求填入本轮指定页面后，读取 [Confluence 写入](references/confluence.md)，完成目标单元格写入、回读及保存核验。已有相同范围的授权不重复询问，草稿与发布分别按用户要求执行。

完成时说明实际交付状态及剩余证据缺口。范围确认、内容确认和页面写入是不同边界；不将一个边界的回答推定为全部授权。
