# 默认刻度与数值

项目已有设计系统时以项目为准；没有时用这里的默认值起步。标注「原书」的数值来自书中示例；标注「本 skill 默认」的是为了可直接落地而补的起点，不是书里给的。

## 间距与尺寸（原书）

基准 16px，小端密、大端疏，相邻值至少相差约 25%：

| token | px | 倍数 |
|---|---|---|
| 1 | 4 | 0.25 |
| 2 | 8 | 0.5 |
| 3 | 12 | 0.75 |
| 4 | 16 | 1 |
| 5 | 24 | 1.5 |
| 6 | 32 | 2 |
| 7 | 48 | 3 |
| 8 | 64 | 4 |
| 9 | 96 | 6 |
| 10 | 128 | 8 |
| 11 | 192 | 12 |
| 12 | 256 | 16 |
| 13 | 384 | 24 |
| 14 | 512 | 32 |
| 15 | 640 | 40 |
| 16 | 768 | 48 |

同一刻度用于 margin、padding、宽高、图标尺寸（如小图标只在 12/16/24/32 中选）。

## 字号（原书）

`12, 14, 16, 18, 20, 24, 30, 36, 48, 60, 72`（px）。

- 用 px 或 rem 定义，不用 em。
- 小屏上大字号要比小字号缩得更多（例：桌面标题 45px / 正文 18px，手机标题约 20–24px / 正文 14px）。

## 字重（原书）

- 正文：400 或 500（视字体而定）。
- 强调：600 或 700。
- UI 小字不用低于 400 的字重；细字重只给大标题。

## 文字颜色层级

原书只规定分 2–3 级，示例卡片（白底）用的是：

- 主要：`hsl(202, 57%, 15%)`
- 次要：`hsl(201, 23%, 34%)`
- 三级：`hsl(203, 15%, 47%)`

本 skill 默认：主要取灰阶最深一级；次要、三级依次变浅，但**每一级都要在实际背景上满足对比度**（正文 4.5:1）。白底上的纯灰，明度约 54% 已不达标（原书对比度表：3.45:1），三级文字一般不要浅于明度约 45%。

彩色背景上不用灰色：取背景同色相，手调饱和度和明度。

## 行高与行长（原书）

- 正文行高起点 1.5；行越长行高越大，宽段落可到 2。
- 字号越大行高越小，大标题可以 1。
- 段落每行 45–75 字符，Web 上约 `max-width: 20em–35em`。中文按字数大致对应每行 25–40 个汉字（本 skill 默认，书中未涉及中文）。

## 字间距（原书）

- 正文：不调整。
- 用正文字体做标题：约 `-0.05em`（收紧）。
- 全大写文本：约 `+0.05em`（放宽）。

## 系统字体栈（原书）

```css
font-family: -apple-system, "Segoe UI", Roboto, "Noto Sans", Ubuntu, Cantarell, "Helvetica Neue", sans-serif;
```

中文界面在其后追加 `"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC"`（本 skill 默认）。

## 色板结构（原书方法）

- 灰色 8–10 级；主色 1–2 个，每个 5–10 级；强调色（新功能高亮、红/黄/绿语义色）每个也要多级。
- 命名 100（最浅）… 500（基色）… 900（最深），9 级。
- 构建顺序：500（适合当按钮背景）→ 900（做文字）与 100（做浅底）→ 700、300 → 800、600、400、200。
- 越靠两端饱和度越高（U 形曲线）；浅色相（如黄）变深时色相往橙方向转，转幅 ≤ 20–30°。
- 渐变背景两端色相相差 ≤ 30°。

冷灰示例（原书，HSL）：`209 15% 28%`、`207 12% 43%`、`208 12% 58%`、`210 16% 76%`、`208 21% 88%`——饱和度两端高、中间低。暖灰同理用色相约 39–41°。

## 感知亮度（原书）

```
亮度 = sqrt(0.299·R² + 0.587·G² + 0.114·B²) / 255
```

峰值色相：黄 60°、青 180°、品红 300°；谷值：红 0°、绿 120°、蓝 240°。

## 对比度（WCAG，原书引用）

- 正文（约 18px 以下）≥ 4.5:1。
- 大字 ≥ 3:1。
- 彩色底白字不达标时：改成浅色底 + 深色同色相文字（翻转对比），或把文字色相转向更亮的色相。

## 阴影

### 单层 5 级（原书）

```css
--shadow-1: 0 1px 3px hsla(0, 0%, 0%, .2);
--shadow-2: 0 4px 6px hsla(0, 0%, 0%, .2);
--shadow-3: 0 5px 15px hsla(0, 0%, 0%, .2);
--shadow-4: 0 10px 24px hsla(0, 0%, 0%, .2);
--shadow-5: 0 15px 35px hsla(0, 0%, 0%, .2);
```

原书只说按钮用小阴影、下拉菜单用中阴影、模态框用大阴影；对应到 1/3/5 级是本 skill 默认。

### 双层 5 级（原书）

第一层大而柔（直射光），第二层小而暗（环境光遮蔽），高度越高第二层越淡：

```css
--shadow-1: 0 1px 3px rgba(0,0,0,.12), 0 1px 2px rgba(0,0,0,.24);
--shadow-2: 0 3px 6px rgba(0,0,0,.15), 0 2px 4px rgba(0,0,0,.12);
--shadow-3: 0 10px 20px rgba(0,0,0,.15), 0 3px 6px rgba(0,0,0,.10);
--shadow-4: 0 15px 25px rgba(0,0,0,.15), 0 5px 10px rgba(0,0,0,.05);
--shadow-5: 0 20px 40px rgba(0,0,0,.2);
```

### 光源效果（原书示例）

```css
/* 凸起按钮：上沿高光（手挑比底色更浅的同色相）+ 下方小阴影 */
.button {
  box-shadow:
    inset 0 1px 0 hsl(224, 84%, 74%),
    0 1px 3px hsla(0, 0%, 0%, .2);
}

/* 凹陷的「井」/输入框：顶部内阴影（底部浅色下唇可用浅色 border-bottom） */
.well { box-shadow: inset 0 2px 2px hsla(0, 0%, 0%, .1); }

/* 扁平风格的实心阴影：零模糊，只有垂直偏移 */
.card-flat { box-shadow: 0 3px 0 hsl(220, 7%, 83%); }

/* 用户上传图片防渗色：半透明内描边 */
.avatar { box-shadow: inset 0 0 0 1px hsla(0, 0%, 0%, .1); }
```

### 交互

- 拖拽中：提升到更高一级阴影。
- 按下：降一级或去掉阴影。

## 图片上的文字（原书示例）

```css
/* 黑色叠加层 */
.hero::before { background-color: hsla(0, 0%, 0%, .55); }

/* 文字光晕：大模糊、零偏移 */
.hero-title { text-shadow: 0 0 50px hsla(0, 0%, 0%, .4); }
```

其他手段：降低图片对比度（书中示例约 -70%，配合亮度 +40% 补偿）；单色着色 = 降对比 → 去饱和 → 正片叠底纯色。

## 圆角（本 skill 默认）

书中只给原则（小=中性、大=活泼、无=正式、全局一致），未给刻度。起点：`0, 2, 4, 8, 12, 16, 9999(全圆)`，项目只挑其中两三个使用。

## iOS 对照（本 skill 默认）

| Web | iOS |
|---|---|
| 间距/字号 px | pt，数值沿用同一刻度 |
| 400/500/600/700 | `.regular/.medium/.semibold/.bold` |
| 双层 box-shadow | 两层 `shadow` 修饰或两个 `CALayer` |
| `align-items: baseline` | `HStack(alignment: .firstTextBaseline)` |
| `max-width` | `.frame(maxWidth:)` |
| `object-fit: cover` | `.scaledToFill().clipped()` |

使用动态字体时，以系统文字样式为刻度，层次原则（字重、颜色分级）照用。
